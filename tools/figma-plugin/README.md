# All My Trips 화면 점검 — Figma 플러그인

Figma 파일의 프레임과 **코드의 화면 목록**을 대조합니다. 시안에 빠진 화면, 코드에 없는데 시안에만 있는 프레임을 찾아 줍니다.

## 왜 플러그인인가

Figma REST API는 파일 내용에 대해 **읽기 전용**입니다. 토큰이 있어도 프레임을 만들거나 고칠 수 없습니다. Figma 파일을 바꾸는 길은 플러그인 API 하나뿐이고, 그건 Figma 안에서 실행돼야 합니다.

## 무엇을 하고, 무엇을 하지 않나

| 한다 | 하지 않는다 |
| --- | --- |
| 파일 전체 프레임을 코드의 화면 목록과 대조 | 기존 프레임 이름 바꾸기 |
| 빠진 화면을 **별도 페이지**에 자리 프레임으로 생성 | 기존 프레임 지우기 |
| 짝을 찾지 못한 프레임을 목록으로 알려 주기 | 기존 페이지에 무언가 끼워 넣기 |

**사람이 그린 시안은 건드리지 않습니다.** 이름만 보고 같은 화면인지 판단하는 것이 확실하지 않고, 디자인 작업은 자동으로 되돌리기가 어렵기 때문입니다. 만들어 둔 것이 마음에 안 들면 `코드 기준 — 자동 생성` 페이지만 지우면 원래대로입니다.

지워야 할 프레임과 이름을 고쳐야 할 프레임은 **알려만 주고 판단은 사람이 합니다.** 시안에만 있는 프레임은 지워야 할 것일 수도, 아직 안 만든 화면일 수도, 부품이나 표지처럼 화면이 아닌 것일 수도 있습니다.

## 쓰는 법

1. Figma 데스크톱 앱을 엽니다 (브라우저에서는 개발 모드 플러그인을 못 씁니다)
2. 메뉴 → `Plugins` → `Development` → `Import plugin from manifest…`
3. 이 폴더의 `manifest.json`을 고릅니다
4. 점검할 파일을 열고 `Plugins` → `Development` → `All My Trips 화면 점검`
5. **점검하기** → 결과 확인 → 필요하면 **빠진 화면 만들기**

창 아래쪽 상자의 내용을 복사하면 결과를 그대로 공유할 수 있습니다.

## 화면 목록을 갱신할 때

화면 목록의 출처는 `src/main/resources/static/js/app.js`의 `ALL_MY_TRIPS_SCREENS` **한 곳**입니다. 화면이 늘거나 줄면 거기만 고치고, 아래를 돌려 플러그인에 다시 심습니다.

```bash
node tools/figma-plugin/build-screens.js
```

`code.js`의 `// <screens>` 구간만 갈아 끼웁니다. 그 구간은 손으로 고치지 마세요 — 다음 실행에서 덮어씁니다.

목록을 손으로 옮겨 적으면 두 곳이 갈립니다. 예전에 `ALL_MY_TRIPS_SCREENS`가 세 파일에 복사돼 22개 / 20개 / 20개로 갈렸던 적이 있습니다.

## 대조 규칙 확인

프레임 짝짓기가 틀리면 리포트 전체가 거짓말이 됩니다. 있는 화면을 없다고 하면 쓸데없는 프레임을 만들고, 없는 화면을 있다고 하면 빠진 채로 넘어갑니다.

```bash
node tools/figma-plugin/match.test.js
```

## 짝짓는 방법

1. **주소** — 프레임 이름에 `/pay/toss` 같은 주소가 적혀 있으면 그걸로 맞춥니다. 이름은 사람이 바꾸기 쉽지만 주소는 화면을 특정하는 값이라 더 확실합니다
2. **이름** — 띄어쓰기·구분 기호를 걷어내고 견줍니다. `예약 · 내 예약`과 `[예약] 내예약 v2`는 같은 것으로 봅니다
3. 한 프레임은 한 화면에만 붙습니다. 둘이 같은 프레임을 가리키면 뒤쪽은 없는 것으로 셉니다

프레임 이름에 주소를 적어 두면 제일 정확합니다.
